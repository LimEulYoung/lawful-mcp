# Security Policy

This policy covers this repository and the hosted service
(`mcp.crow-tit.com`, `api.crow-tit.com`, `console.crow-tit.com`).

## Reporting a vulnerability

Email **ducut91@gmail.com**. Please include what you found, steps to
reproduce, and the affected endpoint or tool if relevant.

We aim to acknowledge reports within 3 business days and investigate
every report. Please report privately by email rather than opening a
public issue, and allow a reasonable window for a fix before public
disclosure.
